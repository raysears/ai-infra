## ai-infra rules — every session, every subagent. Each rule carries the incident that bought it, or the mechanism that makes it true.
- Branch from `origin/<default-branch>` explicitly, never from whatever is checked out, and never commit on the default branch. Local main once carried someone else's unpushed commit into a merged PR (2026-08-07). A hook blocks commits on main; this line says why.
- `git status` and `git branch --show-current` before your first edit. Uncommitted changes you did not make belong to someone else: leave them alone and say so.
- Stage named paths. `git add -A` swept a human's in-progress work into an agent's commit (2026-08-07); `-A`, `--all`, `.` and `-u` are denied in generated settings, this line says why. `git diff --cached --name-only` before every commit.
- `git checkout <file>` and `git restore <file>` only on committed files; against uncommitted work they destroy it, and that has happened. Never rewrite pushed history; recover forward.
- Run every command before you write it into a doc. Two documented commands were broken for months and nobody noticed, which discounted everything else in the file (2026-08-26).
- Docs, comments, names, test names and PR descriptions are leads, not evidence. Verify against the code that produces the behaviour, never the artifact it produced: a verdict checked against a file and never the live system shipped repair SQL for a problem that did not exist (2026-08-26).
- Never type a date literal into a query or report; derive the window from the clock, state the anchor time on line 1, and never trust a zero-result query without a positive control on a window that must contain data. A wrong believed date produced a phantom fleet-wide outage report (2026-08-21).
- If you have already broken one of these, say so plainly and fix it before anything else. Silent cleanup is worse than the mistake.
- If `NTFY_TOPIC` is set, page the human for a blocker you cannot resolve or a finished multi-hour run: `bash {{PLUGIN_ROOT}}/scripts/notify.sh "<title>" "<message>"`. Never for progress, never with personal data, and not at all when the project's own alerting owns paging.
- If this repo has an `AGENTS.md`, its "Things that surprise people" section outranks your assumptions. If `.claude/state/MAP.md` or `.claude/state/HANDOFF.md` exists, read it before exploring. If none exist, proceed silently.
- When something bites you that a competent agent landing cold would have assumed the opposite of, tell the human to run `/lesson` with what happened and what it cost. You cannot run it yourself.
